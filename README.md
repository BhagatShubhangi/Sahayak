# Sahayak 🌍🚨
### *Aapka Suraksha, Hamara Vachan*

> **Sahayak** is a crowdsourced disaster reporting web platform designed to improve emergency response through real-time, community-driven incident reporting.

The platform allows people to quickly report natural disasters and emergencies happening around them so critical information can reach responders and communities faster.


## 🧩 Problem Statement

During disasters like floods, earthquakes, fires, or other emergencies, real-time local information is often delayed or inaccessible.

This delay affects:
- ⏱️ Emergency response speed
- 🚁 Rescue coordination
- 📢 Public awareness
- 📦 Resource distribution

**Sahayak** solves this by creating a simple digital platform where users can report incidents instantly and help authorities and community members stay informed.


## ✨ Features

| Feature | Description |
|---|---|
| 📢 **Incident Reporting** | Users can submit reports about disasters or emergencies happening nearby |
| 📊 **Dashboard** | View reported incidents and important updates in one place |
| 🏠 **Home Page** | Landing page introducing the platform and its purpose |
| ℹ️ **About Us** | Information about the mission and vision behind Sahayak |
| 📞 **Contact Page** | Allows users to connect with the team |
| 📱 **Responsive Design** | Accessible through desktop and mobile browsers |

## 🚀 How to Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/BhagatShubhangi/Sahayak.git
```

**2. Open the project folder**
```bash
cd Sahayak
```

**3. Run the project**

- Open `index.html` directly in your browser, **or**
- Use **VS Code Live Server** for a better development experience
